NOVA BLOOM is a 2D side-scrolling space shooter for Roblox, drawn in a ScreenGui. A seed ship makes dead space bloom: each kill adds colour, and the combo unlocks Petal Spread, Comet Lance and Supernova. It has 3 sectors, 3 enemies, a boss with 3 phases, and the Campaign and Endless modes. The server owns the score, the combo and the mode. The client draws the game and sends the input.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
